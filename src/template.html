          Repository

          GitHub → Settings → Developer settings → Fine-grained tokens. Give it access to this one repository only, with Contents: Read and write. It is used only to save config.json.

          Publish

          Visitors’ browsers can read published keys. Restrict the Cesium token’s Allowed URLs and the Google key’s websites to this site’s address first.

          Not recommended: Open-Meteo keys cannot be limited to one website, so anyone could use your quota.

          Keys stay in this browser and go only to Cesium or Google. With Google tiles, place-name search is turned off because Google’s terms require their own geocoder; enter coordinates instead.

          A scene file holds the site, arrays, obstacles and model settings, not your keys.
